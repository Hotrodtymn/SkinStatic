# SkinStatic

SkinStatic is a Next.js 16, React 19, and TypeScript project developed during a frontend internship with Skinstric AI. It presents an image-upload and skin-analysis workflow and uses Tailwind CSS and Three.js libraries.

## Live site

[Open the deployed website](https://skinstatic-intern.vercel.app/)

## Local development

Install Node.js and npm:

```bash
npm install
npm run dev
```

Visit the local address printed by the development server (typically http://localhost:3000).

## Scripts

- `npm run dev` — development server
- `npm run build` — production build
- `npm run lint` — lint source code

## Notes

External skin-analysis features require working API access. This README does not claim clinical or diagnostic accuracy.
